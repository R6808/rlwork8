校园公共信息与数据展示中心 · 设计思路图

服务对象：云南大学在校学生　｜　解决的问题：查自习室空位、看场所使用热度、找校园建筑位置，三件事散在不同地方，本作品把它们集中到一个入口
① 数据层（唯一数据源，保证各页面数字一致）

meta标题与数据来源声明

seatSlots5 个时间段
activities8 条场所使用指数
usageTrend4 个场所 × 7 天趋势
grades成绩示例数据

② 公共逻辑层（js/main.js，所有页面共用）
Campus.loadCampusData()
fetch 加载 JSON，判断 response.ok，失败抛给 catch
Campus.getSeatStatus()
把剩余座位翻译成 充足 / 紧张 / 已满 三档状态
Campus.readBookings() / saveBookings()
localStorage 读写，内部包 try...catch 防数据损坏
markActiveNav()
按当前文件名给导航项加高亮与 aria-current
▼
③ 功能模块层（5 个页面 + 统一顶部导航，当前页高亮）
home.html　首页
4 个数据概览卡 + 5 个模块入口 + 模块使用顺序说明
study-room.html　自习室查询
按时间段 / 关键字 / 状态三重筛选；点击加入预约；预约存 localStorage
dashboard.html　数据看板
ECharts 柱状图 + 饼图；jQuery 类型筛选；与自习室数据的对应表
charts.html　双库图表
Chart.js 折线图 + 环形图；同页放 ECharts 柱状图作对照
three-d/scene.html　Three.js 三维导览
校园微缩场景：地面、两栋教学楼、圆顶图书馆、旗杆红旗、三棵树；环境光 + 平行光；OrbitControls 拖拽旋转与滚轮缩放；红旗顶点动画 + 场景自转
a-frame/campus.html　A-Frame 场景
同样的校园场景用声明式标签实现：a-sky / a-plane / a-box / a-sphere / a-cylinder；旋转由 animation 组件声明

④ 质量保障（贯穿开发全程）
错误三状态处理
断网 → 提示检查网络；空数据 → 提示无记录并清空图表；JSON 格式错 → 提示解析失败位置
响应式适配
Bootstrap 栅格 + 自定义媒体查询；375 / 768 / 1440px 三档均无横向滚动
测试与仓库
15 个测试用例（正常 + 异常）全部通过；Git 分步提交，提交说明写明具体改动
技术栈：HTML / CSS / Bootstrap 5.3.3 / 原生 JavaScript / jQuery 3.7.1 / ECharts 5.5.1 / Chart.js 4.4.4 / Three.js / A-Frame
