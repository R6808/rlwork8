自查说明

1. 三档宽度

桌面 1440px、平板 768px、手机 375px 三档分别检查首页、自习室查询、数据看板与三维导览。 检查方法：读取 document.documentElement.scrollWidth 与 window.innerWidth 比较， 两者相等即无横向滚动条；导航在窄屏下由 Bootstrap 的 navbar-toggler 折叠为汉堡菜单。

2. 错误三状态

三种异常都用"故意实验"的方式验证：

  • 断网（数据文件取不到）：把数据地址指向不存在的文件，页面显示"数据加载失败"，并提示检查网络与文件。
  • 数据为空：使用空数组的数据文件，看板清空图表并提示"空数据"，首页数字显示为 0，自习室列表显示"没有符合条件"。
  • 数据格式错：使用内容损坏的 JSON 文件，JSON.parse 抛错被 catch 接住，页面显示失败提示而不是白屏。

3. 可访问性与键盘

  • 全部表单控件（时间段、区域名称、座位状态）都有配对的 <label for>。
  • 座位状态用"充足 / 紧张 / 已满"文字加颜色双重表达，不依赖颜色单独传达信息。
  • 图表容器加了 role="img" 与 aria-label，说明图表表达的内容。
  • 导航当前项同时使用 active 类与 aria-current="page"。
  • 只用 Tab 键可以依次走完导航、筛选表单、卡片按钮与预约按钮。

4. 控制台

四个页面在 Chrome 与 Edge 中分别打开，Console 均无红色报错。 代码中没有"注释掉报错代码"的做法；唯一主动打印的是异常分支里的 console.error， 用于在数据加载失败时留下可排查的线索，属于预期输出。
